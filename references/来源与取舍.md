# 来源与通用化取舍

提取日期：2026-10-25，来源为本机 QQ-agent 当前工作树，不是公开 main 分支。来源树已有大量其他未提交工作，本任务只向独立目录写入，没有借机提交、重置或清理原工程。

## 实际提取的工程

| 来源位置 | 实际职责 | 独立包中的位置 |
| --- | --- | --- |
| `prompts/character.md` | AI 身份与不编造肉身经历 | 通用运行规则；精确原文在 evidence/source/prompts |
| `prompts/conversation.md` | 群聊参与、意图、中文表达 | 通用规则与 100 问参与测试 |
| `prompts/anti_template.md` | 原工程人工迭代的具体行为偏好 | 精确原文保留；通用规则按场景合并 |
| `plugins/natural-dialogue/plugin.json` | 默认 observe、范围、修订与压制参数 | 精确快照 + config/style.json 映射 |
| `plugins/natural-dialogue/index.js` 的 `check`、`reviseText`、`hooks` | 词面观察、有限删除、成功发送后的历史 | 完整零依赖快照 natural-dialogue.mjs；新观察适配器复用 check |
| `src/send-guard.js` 的 `reviewOutgoing`、`validRevision` | 统一发送审查与明确请求保护 | 源码文本快照；接入约束 |
| `src/expression-memory.js` | 成功发送后的表达特征、语境、相似度和短摘要 | 源码文本快照；持久参数设计与分会话原则 |

`evidence/source-map.json` 记录每个快照的来源相对路径、SHA-256 和函数定位。源码文本快照只是证据，不是复制到别的项目就能直接运行的完整模块。独立观察器所用的 natural-dialogue.mjs 没有外部 import，其余来源模块有原工程依赖，所以保留为 .txt，避免误装。

没有复制真实群号配置、data/config.json、聊天原文、私有角色卡、用户记忆、模型权重或 API 密钥。live 采集仅在发请求时读取用户现有模型配置；目录中保留模型名和接口哈希，未记录接口密钥。

## 规则并非原文盲目叠加

原工程曾针对特定群聊人工调整，存在互相拉扯的要求，例如“认错只说知道了”和“说明具体错在哪里”，以及“不要清单”与技术求助的步骤要求。作为任意场景可加载的 agent，不能把这些当没有例外的普遍语言规律。

本包做了以下明确取舍：

- 保留短句、少客服填充、少固定开头结尾、不过度解释自己、不自动总结、澄清陌生输入、不编工具结果、不伪装人类。
- 保留离世消息默认“节哀”，同时给明确的请假短信等求助留出空间。
- 区分口吻反馈与事实纠正：口吻可简短确认，事实必须更正。
- 不全局禁止破折号、清单、“不是而是”和超过十行的代码。它们在闲聊中过度出现才可能是问题；技术准确性和用户明确格式要求优先。
- 原文包含被辱骂后必须用粗口还击的特定偏好。本包保留原文证据，但不把它装成跨场景默认行为；通用默认是可以有态度，不强制辱骂。
- 原平台的管理员身份和恶意诱导判定不能照搬到所有 AI。保留可信来源和参与边界原则，直接正常求助不因身份普通而被拒绝。
- 默认只观察，不自动删句或压制。正则命中可以提醒人工，不能代替语义与语境判断。

这些是为可移植性进行的工程选择，不是声称原工程每条人工偏好已经被同样迁移或在任意模型上有效。需要精确复刻旧 bot 时，将原文与目标环境的要求逐项核对，在测试通道验证，不把全部证据文件塞进系统提示。

历史文档里的性能和人工审核记录属于原工程，本包没有把它们当本轮结果。此交付的自动测试、模型采集与待人审状态单独记录在交付验证中。
